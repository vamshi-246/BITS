K=3200 N=2 LTE Tail Paper-Boundary Regression
=============================================

Saved after revising Phase 4 to keep the two-SISO RTL constraint while moving
to the paper code-block length and QPP.

Configuration:
- K=3200
- NUM_SISO=2
- SEG_LEN=1600
- QPP f1=111, f2=240
- WIN_LEN=30
- TAIL_LEN=3 on the last SISO core
- NUM_HALF_ITER=11
- PAPER_BOUNDARY=1
- Eb/N0=1.0 dB, code rate=1/3, seed=42

Commands:

```powershell
python scripts\qpp_6144_gen.py --K 3200
python scripts\gen_encoded_test_vectors.py --K 3200 --num-siso 2 --include-tail --seed 42
iverilog -g2012 -P tb_turbo_decoder.TEST_K=3200 -P tb_turbo_decoder.TEST_TAIL_LEN=3 -P tb_turbo_decoder.TEST_PAPER_BOUNDARY=1 -P tb_turbo_decoder.TEST_QPP_LUT_FILE='"data/qpp_3200.hex"' -o tb\tb_turbo_decoder_k3200_paper_check.vvp tb\tb_turbo_decoder.v rtl\*.v
vvp tb\tb_turbo_decoder_k3200_paper_check.vvp
python scripts\turbo_ref_model.py --K 3200 --num-siso 2 --tail-len 3 --boundary-mode paper --show-mismatches 10
```

Result:
- Channel hard decisions: 577/3200 = 0.180312
- Python reference final L_D BER: 90/3200 = 0.028125
- RTL final L_D BER: 90/3200 = 0.028125
- RTL-vs-reference intrinsic mismatches: 0/3200
- RTL-vs-reference hard-bit mismatches: 0/3200
- RTL-vs-reference final-extrinsic mismatches: 0/3200

Files:
- `qpp_3200.hex`: SISO-0 QPP LUT for K=3200/N=2.
- `vector_metadata.txt`: vector generation settings and channel BER.
- `*_ram.hex`: exact input LLR BRAM images used by the RTL testbench.
- `true_info_bits.txt`, `tail_bits.txt`: transmitted information and LTE tail bits.
- `rtl_final_intrinsic.txt`, `rtl_final_hard_bits.txt`: RTL final decision outputs.
- `ref_final_intrinsic.txt`, `ref_final_hard_bits.txt`, `ref_final_extrinsic.hex`: Python reference outputs.
- `ld_ram_output.hex`: RTL final extrinsic BRAM dump.
- `ber_results.txt`: BER and mismatch report generated by `scripts/turbo_ref_model.py`.
- `rtl_boundary_trace_k3200_2half.txt`: optional two-half debug trace used while validating the interleaved boundary path.
