======================================

Saved after Phase 3 paper-boundary RTL changes.

Configuration:
- K=6144
- NUM_SISO=2
- SEG_LEN=3072
- WIN_LEN=30
- TAIL_LEN=3
- NUM_HALF_ITER=11
- PAPER_BOUNDARY=1

Commands:

```powershell
iverilog -g2012 -P tb_turbo_decoder.TEST_TAIL_LEN=3 -P tb_turbo_decoder.TEST_PAPER_BOUNDARY=1 -o tb\tb_turbo_decoder_paper_check.vvp tb\tb_turbo_decoder.v rtl\*.v
vvp tb\tb_turbo_decoder_paper_check.vvp
python scripts\turbo_ref_model.py --tail-len 3 --boundary-mode paper --show-mismatches 10
```

- Python reference final L_D BER: 157/6144 = 0.025553
- RTL final L_D BER: 157/6144 = 0.025553
- RTL-vs-reference intrinsic mismatches: 0/6144
- RTL-vs-reference hard-bit mismatches: 0/6144
- RTL-vs-reference final-extrinsic mismatches: 0/6144

Files:
- `*_ram.hex`: exact input LLR BRAM images used by the RTL testbench.
- `true_info_bits.txt`, `tail_bits.txt`: transmitted information and LTE tail bits.
- `rtl_final_intrinsic.txt`, `rtl_final_hard_bits.txt`: RTL final decision outputs.
- `ref_final_intrinsic.txt`, `ref_final_hard_bits.txt`, `ref_final_extrinsic.hex`: Python reference outputs.
- `ld_ram_output.hex`: RTL final extrinsic BRAM dump.
- `ber_results.txt`: BER and mismatch report generated by `scripts/turbo_ref_model.py`.
- `rtl_boundary_trace_1half.txt`: optional one-half debug trace from `+trace_boundary`, used to check dummy-forward alpha and DBR boundary beta/input behavior.
